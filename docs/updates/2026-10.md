## U-20261001-02 · 2026-10-01 · Every MCP tool is a CLI subcommand, and the CLI gained the MCP tools' options · #done #cli #mcp #docs #i18n

- **What**: every MCP tool is now also a `py -m Imervue.cli` subcommand. `Imervue/cli_tools.py` builds the 46 the CLI lacked from each tool's JSON input schema and calls the MCP handler itself: `source` + `destination` tools are batch writers on the shared `inputs` / `--out` / `--dry-run` / `-j` arguments (`<stem>_<name>.png`, `.puppet` for `puppet-from-png`, `ela` decodes the map to a PNG), `path` tools are per-image reporters with `--json`, and folder / GPS tools run once and print JSON. - **Fix**: MCP `convert_format` to a `.tif` destination raised `KeyError('TIF')` inside Pillow; `.tif` now maps to TIFF like `.jpg` to JPEG.
- **Result / numbers**: CLI subcommands 18 → 64. `tests/test_cli_tools.py` fails when an MCP tool has no CLI subcommand, and checks every generated option against its schema.
