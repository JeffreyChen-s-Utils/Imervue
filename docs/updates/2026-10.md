## U-20261001-03 · 2026-10-01 · Library scans read only new or changed files, on several threads, and fill in missing pHashes · #done #library #performance #docs #i18n

- **What**: library scans are incremental and parallel. `Imervue/library/scanner.py` first skips, on the scanner thread, every file whose mtime and size match its row; a row without a pHash is not skipped when the scan computes pHashes, so a file first indexed with **Compute perceptual hash** off gets one on the next pHash scan (before, every later scan skipped it). The files left are decoded for size and pHash on a thread pool (`probe_workers()`: every core but one, 1 to 8) with the database lock free, so cull / tag writes from the UI no longer wait behind a 256-file chunk of decoding; each chunk's rows are then written in one transaction. A rescanned file's size and pHash now describe its current content: `image_index.set_decoded_fields` replaces them, and clears them when the scan did not or could not read the file (before, a changed file scanned without pHash kept its old hash). Progress is reported every 10 files and at each chunk's end, skipped files included. Removing rows of deleted files stays with Library Maintenance's prune, which keeps a row's notes, tags and cull flags until the user prunes it.
- **Result / numbers**: 200 JPEGs of 1024x768 with pHash, first scan 4.68 s on one thread vs 0.78 s on 8 (this 12-thread machine); an unchanged rescan 0.05-0.07 s either way. Nine new tests in `tests/test_library_scanner.py` (backfill, no re-read of unchanged files, stale-hash clearing, worker threads with the lock free, progress, cancel mid-chunk, failing probe, worker count) plus `set_decoded_fields`.
- **Files**: `Imervue/library/scanner.py`, `Imervue/library/image_index.py`, `tests/test_library_scanner.py`, `README.md` + 9 translations and `docs/*/index.rst` (Library Search), `architecture_explore.md`.

## U-20261001-04 · 2026-10-01 · Semantic Search runs CLIP on onnxruntime instead of torch, and Auto-Tag uses it · #done #clip #library #onnx #docs #i18n

- **What**: Semantic Search no longer needs PyTorch. `Imervue/library/clip_onnx.py` runs CLIP ViT-B/32 on onnxruntime from the int8-quantised ONNX export `Xenova/clip-vit-base-patch32` pinned at commit `d15189d7028b43f1d3e65039190477f6af591c2a` (text + vision encoders, 153 MB, downloaded once into the Hugging Face cache); images are prepared as CLIP was trained (shortest edge 224 bicubic, centre crop, OpenAI mean / std). `Imervue/library/clip_tokenizer.py` is a plain-Python CLIP byte-level BPE tokenizer reading the model's `vocab.json` / `merges.txt`, so neither `tokenizers` nor `transformers` is needed. Providers are CUDA (an NVIDIA card, never an integrated GPU) or the CPU; DirectML is left out because its default device on a hybrid laptop is often the integrated GPU. When onnxruntime is missing, the menu entry runs the dependency installer and then opens the search; the first build says it is downloading the model; a model that can't be loaded (offline) is reported in the dialog instead of failing every picture. The cache records the model id, and a cache written by another model (the old open_clip one) is rebuilt. `auto_tag.try_clip_labels`, a stub that always returned `[]`, now gives zero-shot CLIP labels (up to three of its ten prompts) once the model has been downloaded; Auto-Tag never starts the download. The old open_clip / torch backend is removed.
- **Result / numbers**: the tokenizer matches the reference `tokenizers` implementation id for id on 17 hand-picked phrases and 5000 random strings (letters, digits, symbols, CJK, emoji, combining accents, `<|endoftext|>` markers). On this machine (onnxruntime-gpu without the CUDA 12 libraries, so CPU) an image embeds in 20-30 ms and the model loads in 1.8 s; solid red / blue / green test images rank "a red / blue / green image" first. New tests: `tests/test_clip_tokenizer.py` (28, on the model's own vocabulary subset), `tests/test_clip_onnx.py` (29, fake onnxruntime and Hub), plus model-id, install and failure cases in `test_clip_search.py`, `test_semantic_search_dialog.py`, `test_auto_tag.py`.
- **Files**: `Imervue/library/clip_onnx.py`, `Imervue/library/clip_tokenizer.py` (new), `Imervue/library/clip_search.py`, `Imervue/library/auto_tag.py`, `Imervue/gui/semantic_search_dialog.py`, `Imervue/multi_language/{english,traditional_chinese,chinese,japanese,korean}.py`, tests above, `README.md` + 9 translations, `docs/*/index.rst`, `THIRD_PARTY_LICENSES.md`, `architecture.md` §1, `architecture_explore.md`.
