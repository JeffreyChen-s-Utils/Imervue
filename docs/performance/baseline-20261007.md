Startup including QApplication/imports/constructor took 2,460.78ms. Image-frame measurements have
a warmed file cache from the preceding decode measurement. Warm decode retains the previous array
until the next decode finishes, like a viewer retaining its displayed image. The GL wall verifies
white visible pixels and uses 12,233,410 texture bytes in both library sizes (identical viewport).
Paint's six arrays contain 199,065,600 bytes; its native autosave bundle is 41,102,958 bytes.
Reported RSS includes setup, source images and earlier retained state in the same scenario;
see raw data for operation growth and process-lifetime peaks.

## Targets for subsequent stages

These are acceptance requirements, **not achieved results**. Compare at least three independent
reports on the same fixture/hardware before treating small differences as regressions or gains.
Correctness tests are mandatory even when a timing target passes.

| Stage | Acceptance requirement | Required correctness evidence |
| --- | --- | --- |
| #63 Modify preview | UI request/slider callbacks p95 ≤25ms; interactive preview at ≤1MP p95 ≤300ms; final full result no more than 20% slower than this CPU reference | Latest request wins across rapid edits/image switches; full logical geometry; full-resolution saved pixels, alpha and orientation |
| #64 Undo | Default retained history ≤512MiB including baseline and both directions; the 4K 32×32 stroke p95 ≤30ms and history storage ≥60% below four complete snapshots | Full #59 document semantics; regions, structure, masks/vectors/groups; byte/level boundaries; independent mutable restores |
| #65 Thumbnail wall | 100k steady-frame p95 ≤16.7ms and ≤1.2×10k frame time; candidate count tied to viewport/buffer, not library size | Zoom, scroll, selection/hit testing, edge overlap, real GL pixel readback and texture release |
| #66 Decode/prefetch | Cached actual bytes + all in-flight reservations stay within a window's assigned RAM budget; VRAM remains separately bounded | Oversize and simultaneous completion, RAW/panorama size estimates, optional detector missing, multiple windows |
| #67 Autosave | UI enqueue/coalescing p95 ≤25ms; compression/write occurs off UI; final write time ≤1.2×this baseline | One coherent document revision; bounded pending work; old valid files survive failure; close/recovery ownership |
| #68 Worker cancellation | Cancel/close returns to the UI in ≤50ms even when worker computation takes ≥250ms to yield | Signals detached safely; running thread retained until completion; repeated close/reopen; no thread destruction while running |
| #75 Disk cache | Empty/100k-cache foreground constructor p95 ≤10ms; inventory reconciles quota in background | Writes/reads during inventory, failed/corrupt entries, replacement races, legacy cleanup and final byte accounting |
| #76 SQLite | 100k foreground search p95 ≤100ms under normal batch scans; no >20% single-reader regression | No uncommitted/rolled-back rows leak to other threads; concurrent notes/tags, rollback and close/reopen |
| #77 GPU evaluation | Enable an interactive GPU path only with measured benefit and CPU parity; keep a CPU fallback | Shared color/geometry/alpha semantics for preview/export; backend failure and missing dependencies |

Unchanged paths keep median and p95 within 20% of this baseline and preserve memory limits.
Initial limits for cold/warm hidden startup are 3,000/400ms; 10k/100k metadata index 3,500/36,000ms;
100k unchanged scan 31,000ms; metadata-scan cancellation after progress 50ms. These describe the
measured workload, not arbitrary storage, RAW decoding or uninterruptible model inference.
