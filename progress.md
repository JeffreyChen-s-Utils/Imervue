- **#31** [DECIDE] On Windows no folder above the one Imervue shows can be renamed or moved while it shows it (Explorer: the folder or a file in it is open in another program). Any open directory handle blocks renaming the folders above it: measured with `QFileSystemWatcher`, `FindFirstChangeNotification`, a share-all `CreateFileW` handle and watchdog alike, while the watched folder itself can still be renamed or deleted. Imervue holds such handles through the grid's folder watcher (`Imervue/Imervue_main_window.py:201`) and the file tree's `QFileSystemModel` (`Imervue/gui/main_window_layout.py:37`, every folder it has listed); `QFileSystemModel.Option.DontWatchForChanges` released the tree's in the same test. Decide between: keep the live updates and the lock, or poll instead - the grid folder's modification time about once a second (new files show within a second or two rather than at once) and the tree refreshed from its Refresh item or when Imervue comes back to the front.
